# 🍔 Swiggy Sales Analysis Using SQL

## 📌 Project Overview
This project focuses on analyzing Swiggy restaurant and food-related data using SQL Server. The objective is to understand restaurant distribution, food pricing, food categories, customer ratings, and location-wise patterns across different cities in India.

## 🎯 Business Problem
Swiggy has restaurant and food-related data across multiple cities. This project analyzes restaurant availability, menu prices, food categories, and customer ratings to identify meaningful patterns and generate useful business insights.

## 📊 Dataset Description
The dataset contains **197,430 records and 10 columns** related to restaurants, food items, prices, ratings, and locations.

### 🗂️ Dataset Columns
- State
- City
- Order Date
- Restaurant Name
- Location
- Category
- Dish Name
- Price (INR)
- Rating
- Rating Count

### 📈 Dataset Summary
- 📁 Total Records: 197,430
- 🏪 Unique Restaurants: 993
- 🌆 Total Cities: 28
- 🗺️ Total States: 28
- 🍽️ Food Categories: Multiple categories

## ⚠️ Data Limitation
The dataset contains restaurant listings, menu prices, customer ratings, and rating counts. It does not contain transaction-level order IDs or quantities sold. Therefore, actual sales revenue, completed orders, and average order value cannot be calculated reliably.

## 🏁 Conclusion
This project demonstrates how SQL can be used to explore restaurant data, analyze food pricing, evaluate customer ratings, and identify location-wise patterns. The analysis helps generate meaningful insights into restaurant and menu trends across India.
